# موسوعة سرت — موقع ثابت جاهز لـ GitHub Pages

## الملفات
- `index.html`: الموقع العربي كاملًا (RTL) مع التصميم والمحتوى والمراجع وروابط الصور.
- `README.md`: هذا الملف.

## النشر على GitHub
1. أنشئ مستودعًا جديدًا على GitHub، مثل `sirte-history`.
2. ارفع `index.html` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط Save.
6. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages.

التوثيق الرسمي: https://docs.github.com/en/pages/quickstart

## الصور
النسخة الأولية تستخدم صورًا توضيحية خارجية من Unsplash. ليست هذه الصور أرشيفًا موثقًا لسرت، وقد وُضعت تعليقات صريحة بهذا المعنى. في صفحة المراجع توجد روابط لمجموعات صور سرت وليبيا على Wikimedia Commons؛ افحص ترخيص كل صورة قبل إدراجها. الصور الخارجية تحتاج إلى اتصال بالإنترنت كي تظهر.

## التوثيق والتحرير
الموقع يميز بين الوقائع التاريخية، وبيانات الجهات الرسمية عن مشروعاتها، والتقييمات السياسية. راجع المصادر الأصلية قبل تحديث حالة أي مشروع أو نشر تفاصيل جديدة. GitHub Pages يستضيف المواقع الثابتة ولا يشغل PHP أو قواعد بيانات خادمية.
